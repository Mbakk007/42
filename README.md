# 42 Projects

A collection of projects completed as part of the 42 curriculum.
## 📋 About

This repository contains my solutions to 42 School projects.  Each project is designed to teach specific programming concepts.

## 📚 Projects
### MILESTONE 0 ✅###
### Libft
Libft - A custom implementation of the C standard library, recreating essential functions (string, memory, character operations) plus additional utilities. This serves as a reusable library for all future 42 projects.

### MILESTONE 1 ✅###
### ft_printf
Recreation of printf. Handles variadic arguments and multiple format specifiers (%c, %s, %d, %i, %u, %x, %X, %p, %%).

### get_next_line
A function that reads and returns a single line from a file descriptor, one at a time, regardless of line length.
Implements static variables and buffer management to handle multiple FDs simultaneously with configurable BUFFER_SIZE.

### MILESTONE 2 ###
### push_swap
Sorting a stack using a limited set of operations and two stacks (a and b).  
Focuses on algorithmic thinking, choosing efficient strategies, and minimizing the number of moves for different input sizes.

### Python Modules 00-10
A set of small Python modules covering core concepts progressively:
- Python fundamentals: functions, control flow, and type hints
- OOP: classes, encapsulation, inheritance, polymorphism, abstract classes
- Exceptions and error handling
- Collections (lists/tuples/sets/dicts), generators, comprehensions
- File I/O, context managers, and streams
- Imports/packages and avoiding circular dependencies
- Virtual environments, dependency management, and environment configuration
- Data validation with Pydantic models
- Functional programming: lambdas, higher-order functions..

All projects follow the 42 School Norm.
